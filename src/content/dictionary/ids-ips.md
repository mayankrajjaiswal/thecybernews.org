## What is IDS / IPS?

Intrusion Detection System (monitors) / Intrusion Prevention System (blocks). Network security appliances that monitor network or system activities for malicious activity.

## Why it matters
Understanding this concept helps in grasping how modern networks and security systems operate, providing a foundation for more advanced topics.

## Real-world Analogy
> IDS is like a guard dog that barks when someone jumps the fence. IPS is a guard dog that bites.
