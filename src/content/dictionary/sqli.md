## What is SQL Injection (SQLi)?

A code injection technique used to attack data-driven applications, in which malicious SQL statements are inserted into an entry field for execution.

## Why it matters
Understanding this concept helps in grasping how modern networks and security systems operate, providing a foundation for more advanced topics.
