## What is Cross-Site Scripting (XSS)?

A type of security vulnerability typically found in web applications that enables attackers to inject client-side scripts into web pages viewed by other users.

## Why it matters
Understanding this concept helps in grasping how modern networks and security systems operate, providing a foundation for more advanced topics.

## Real-world Analogy
> Like a vandal sneaking a bad message onto a public bulletin board so everyone who walks by is tricked into reading it.
