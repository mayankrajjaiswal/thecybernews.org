## What is a Network Port?

If an IP address is like the street address of an apartment building, a **Port** is like the apartment number. 
When data arrives at a computer, the computer needs to know which application should receive that data. It uses ports to organize the traffic.

## Common Ports You Should Know

- **Port 80 (HTTP):** Used for standard, unencrypted web traffic.
- **Port 443 (HTTPS):** Used for secure, encrypted web traffic. (This is what you want to see when banking!)
- **Port 22 (SSH):** Used for secure remote logins by administrators.
- **Port 53 (DNS):** Used to translate website names (like google.com) into IP addresses.

## Why Ports Matter for Security

If a port is "open", it means a program is actively listening for traffic on that port. Hackers run tools called "Port Scanners" to find open doors into a network. A good firewall blocks access to ports that shouldn't be exposed to the public.
