## What is a Computer Network?

At its core, a computer network is simply two or more computers connected together so they can share information. When you load a website, your computer is talking to another computer (a server) somewhere else in the world.

## The Models that Make it Work

Networking is often taught using two models: the **OSI Model** and the **TCP/IP Model**. 
Think of these models like the postal service. To send a letter, you need to write it, put it in an envelope, write the address, add a stamp, and hand it to the postman. Each of these steps is a "layer" in the networking model.

- **TCP/IP** is the actual language of the internet.
- **OSI** is a theoretical 7-layer model used to help people understand how data travels from a physical cable all the way up to the web browser.

Understanding these layers helps IT professionals figure out where a problem is happening when the internet "stops working."
